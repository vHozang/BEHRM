# Resume scoring skill

- Score only against the supplied CV evidence and JD rubric.
- Never infer a skill, credential, employer, or number of years that is not present in the CV.
- Every non-zero criterion score must include a supporting quote and source page when available.
- Do not use name, photo, gender, age, date of birth, marital status, religion, hometown, or address in scoring.
- Separate mandatory requirements from preferred requirements.
- Return data that conforms to `ai-assessment.v1` and include model and prompt versions.
- Mark low-confidence extraction for mandatory human review.
